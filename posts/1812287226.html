注意力机制的演进

Attention基本原理

[1706.03762] Attention Is All You Need

Query、Key、Value

对于输入序列

$$ X \in \mathbb{R}^{T\times d_{\mathrm{model}}} $$
通过三个不同的线性投影生成 Query、Key 和 Value：
$$ Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V $$
其中：
  • Query：当前 Token 用于查询其他 Token 的特征
  • Key：每个 Token 提供用于匹配的特征
  • Value：每个 Token 实际提供的内容信息

可以将 Attention 理解为：

Query 与所有 Key 计算匹配程度，再根据匹配程度对对应的 Value 进行加权聚合

Scaled Dot-Product Attention

Attention 的计算主要分为三个步骤：

1. 计算 Attention Score

通过 Query 和 Key 的点积衡量不同 Token 之间的匹配程度：

$$ S=\frac{QK^\top}{\sqrt{d_k}} $$

当 Query 和 Key 的维度增大时，点积的数值方差通常也会增大，使 Softmax 更容易进入饱和区域，导致梯度变小

通过除以 $\sqrt{d_k}$ 对点积进行缩放，可以稳定 Attention Score 的数值范围，改善训练稳定性

2. 计算 Attention Weight

对 Attention Score 进行 Softmax，得到归一化的注意力权重：

$$ A=\operatorname{Softmax}(S) $$
**3. 加权聚合 Value**

根据 Attention Weight 对所有 Value 加权求和：

$$ O=AV $$
得到融合上下文信息后的 Token 表示

完整的 Scaled Dot-Product Attention：

$$ \operatorname{Attention}(Q,K,V)= \operatorname{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$

Multi-Head Attention（MHA）

单个 Attention Head 只能通过一组 Q、K、V 投影学习信息交互关系

Multi-Head Attention 将输入投影到多个不同的子空间，分别执行 Attention，再将各个 Head 的结果拼接起来

将所有 Head 的输出拼接，并通过线性投影得到最终结果：

$$ \operatorname{MHA}(Q,K,V)= \operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)W_O $$
不同 Attention Head 可以在不同的投影子空间中学习信息交互关系，从而增强模型对不同上下文特征的表达能力

Causal Mask

在自回归语言模型中，当前 Token 只能访问当前位置及之前的 Token，不能访问未来 Token

因此需要引入 Causal Mask（因果掩码），将 Mask 加入 Attention Score，在 Softmax 之前屏蔽未来位置：

$$ \operatorname{Attention}(Q,K,V)= \operatorname{Softmax}\left( \frac{QK^\top}{\sqrt{d_k}}+M \right)V $$
由于被屏蔽的位置对应 $-\infty$，经过 Softmax 后其注意力权重为 0

Self-Attention 与 Cross-Attention

两者主要区别在于 Query、Key、Value 的来源：

机制 Query 来源 Key / Value 来源 主要作用
Self-Attention 当前序列 当前序列 序列内部信息交互
Cross-Attention 当前序列 另一序列 不同序列之间的信息交互

Self-Attention 中，Q、K、V 都由同一个输入序列投影得到

Cross-Attention 中，Query 通常来自 Decoder，而 Key 和 Value 来自 Encoder 的输出

位置编码

Self-Attention 本身主要根据 Token 内容计算相关性，并不直接包含 Token 的位置信息

虽然包含相同的 Token，但顺序不同，语义也不同

因此，需要向模型引入位置信息，使其能够区分不同 Token 在序列中的位置

常见的位置编码方式：

类型 核心思想 代表方法
绝对位置编码 为每个位置分配独立的位置表示 Sinusoidal Encoding
Learned Position Embedding
相对位置编码 显式建模 Token 之间的相对距离 Relative Position Bias
旋转位置编码 根据位置旋转 Query 和 Key RoPE

RoPE

[2104.09864] RoFormer: Enhanced Transformer with Rotary Position Embedding

核心思想： 根据 Token 的位置对 Query 和 Key 进行旋转，使 Attention 内积自然包含相对位置信息，从而让模型感知 Token 的顺序和距离关系

首先考虑二维向量，对于位置为 $m$ 的 Token，定义旋转矩阵：

$$ R_{m,\theta}= \begin{bmatrix} \cos(m\theta)&-\sin(m\theta)\\ \sin(m\theta)&\cos(m\theta) \end{bmatrix} $$
对 Query 和 Key 分别进行旋转：
$$ \widetilde q_m=R_{m,\theta}q_m \qquad \widetilde k_n=R_{n,\theta}k_n $$
原始 Attention 使用 Query 和 Key 的内积计算相关性，经过 RoPE 旋转后：
$$ \begin{aligned} \widetilde q_m^\top\widetilde k_n &=(R_mq_m)^\top(R_nk_n)\\ &=q_m^\top R_m^\top R_nk_n\\ &=q_m^\top R_{n-m}k_n \end{aligned} $$
利用旋转矩阵的性质：
$$ R_m^\top R_n=R_{n-m} $$
可以发现，旋转后的 Attention 内积不仅与 Query 和 Key 的内容有关，还与两个 Token 之间的相对位置差 $n-m$ 有关

对于多维的情况，需要将相邻维度两两分组，每两个维度构成一个二维旋转平面

$$ (q_0,q_1),\quad (q_2,q_3),\quad \ldots,\quad (q_{d_h-2},q_{d_h-1}) $$
不同维度组使用不同的旋转频率：
$$ \theta_i= 10000^{-\frac{2i}{d_h}}, \qquad i=0,1,\ldots,\frac{d_h}{2}-1 $$
不同频率承担不同尺度的位置表示：
  • 高频维度：相邻位置之间相位变化较明显，提供更细粒度的位置分辨率
  • 低频维度：相位变化较慢，更适合表达较长距离的位置关系

可以类比时钟：

通过不同频率的组合，使模型能够同时感知不同尺度的位置关系

优点 局限
Attention 内积自然包含相对位置信息 超出训练长度时外推性能可能下降
不需要额外学习独立的位置 Embedding 长序列下可能出现相位混叠
只需要旋转 Q、K，计算简单 长上下文需要额外的位置频率调整
保持旋转部分的欧氏范数 与部分低秩 KV 压缩结构需要进行特殊设计

KV Cache 优化

MHA 中，每个 Query Head 都拥有独立的 Key 和 Value

在自回归推理过程中，需要为所有 KV Head 保存历史信息。随着 Attention Head 数量增加，KV Cache 的存储和读取开销也会增加

因此，后续出现了通过多个 Query Head 共享 KV Head 的设计，以减少 KV Cache

方法 代表性模型
MQA PaLM
GQA Llama
MLA Deepseek-V2

Multi-Query Attention（MQA）

[1911.02150] Fast Transformer Decoding: One Write-Head is All You Need

核心思想： 保留多个独立的 Query Head，但让所有 Query Head 共享同一组 Key 和 Value

保留多个 Query Head，但所有 Query Head 共享同一组 Key 和 Value

对于第 $i$ 个 Query Head，其 Attention 计算为：

$$ O_i= \operatorname{Softmax} \left( \frac{Q_iK^\top}{\sqrt{d_h}} \right)V $$
MQA 可以显著减少 KV Cache 的存储量和读取开销，但所有 Query Head 共享同一组 KV，也可能限制不同 Head 对信息的独立表达能力

Grouped-Query Attention（GQA）

[2305.13245] GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints

GQA 在 MHA 和 MQA 之间进行折中

将多个 Query Head 划分为若干组，每组共享一组 Key 和 Value

那么每组 Query Head 的数量为：

$$ G=\frac{H_Q}{H_{KV}} $$
第 $i$ 个 Query Head 的计算可以表示为：
$$ O_i= \operatorname{Softmax} \left( \frac{Q_iK_{g(i)}^\top}{\sqrt{d_h}} \right)V_{g(i)} $$
GQA 可以理解成 MHA 与 MQA 的折中：
  • MHA：KV Head 最多，表达能力完整，但 KV Cache 最大
  • MQA：只保留一组 KV，缓存最小，但共享程度最高
  • GQA：多个 Query Head 分组共享 KV，在表达能力与缓存开销之间折中

Multi-Head Latent Attention（MLA）

[2405.04434] DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model

核心思想： 对 Key 和 Value 进行低秩联合压缩，将原本多个 Attention Head 的 KV 表示映射到一个共享的低维 Latent Vector，在推理时只需要缓存压缩后的潜在向量，从而进一步降低 KV Cache 开销

Low-Rank KV Compression

MQA 和 GQA 通过减少 KV Head 数量降低缓存开销，但仍然需要保存每个 KV Head 对应的完整 Key 和 Value

MLA 则采用不同思路：不再直接保存完整的 K、V，而是将它们共同压缩到一个低维潜在空间，再通过线性投影恢复对应的 K、V 表示

1. KV Down-Projection

首先，将输入隐藏状态映射到一个低维潜在向量：

$$ \mathbf{c}_t^{KV}=W^{DKV}\mathbf{h}_t $$
其中，$\mathbf{c}_t^{KV}$ 是 Key 和 Value 共享的压缩表示，其维度 $d_c$ 远小于原始多头 KV 的总维度

2. KV Up-Projection

通过两个独立的线性投影，从共享的 Latent Vector 恢复 Key 和 Value：

$$ \mathbf{k}_t^C=W^{UK}\mathbf{c}_t^{KV}\\

\mathbf{v}_t^C=W^{UV}\mathbf{c}_t^{KV} $$

推理时只需要缓存 $\mathbf{c}_t^{KV}$，不需要保存完整的 K、V
Query Low-Rank Compression

除了 KV 压缩，MLA 还对 Query 进行低秩压缩：

$$ \mathbf{c}_t^Q=W^{DQ}\mathbf{h}_t\\ \mathbf{q}_t^C=W^{UQ}\mathbf{c}_t^Q $$
Query 同样通过 Down-Projection 和 Up-Projection 完成低秩映射

主要作用： 减少训练过程中的激活显存（Activation Memory），但 Query 压缩本身并不减少推理时的 KV Cache

Decoupled RoPE

MLA 引入低秩 KV 压缩后，会遇到一个问题：RoPE 与低秩压缩之间存在结构冲突

RoPE 需要对 Key 进行位置相关的旋转。如果直接对压缩恢复后的 Key 应用 RoPE：

$$ \widetilde{\mathbf{k}}_t^C = R_tW^{UK}\mathbf{c}_t^{KV} $$
位置相关的旋转矩阵位于 $W^{UK}$ 和 KV Latent 之间，导致 $W^{UK}$ 无法直接吸收到 Query 投影矩阵中，破坏矩阵吸收机制

为了解决这一问题，MLA 提出 Decoupled RoPE（解耦位置编码），将 Query 和 Key 拆分为内容表示与位置表示两部分

$$ \mathbf{q}_{t,i} = [\mathbf{q}_{t,i}^C;\mathbf{q}_{t,i}^R]\\\mathbf{k}_{t,i} = [\mathbf{k}_{t,i}^C;\mathbf{k}_t^R] $$
其中：
  • $\mathbf{q}{t,i}^C$、$\mathbf{k}{t,i}^C$：通过低秩压缩路径生成，负责内容信息交互
  • $\mathbf{q}_{t,i}^R$、$\mathbf{k}_t^R$：独立的位置编码分支，负责引入位置信息

其中，Query 的位置表示按 Head 生成，而位置 Key 在所有 Head 之间共享

RoPE 只作用于独立的位置编码分支：

$$ \mathbf{q}_{t}^{R} = \operatorname{RoPE}(W^{QR}\mathbf{c}_t^Q) \\ \mathbf{k}_{t}^{R} = \operatorname{RoPE}(W^{KR}\mathbf{h}_t) $$
内容信息仍然通过低秩 Latent Vector 进行压缩，而位置信息通过独立的 RoPE 分支引入，避免位置旋转干扰 KV 压缩
Matrix Absorption

MLA 还通过矩阵吸收，避免在推理时显式恢复完整的 Key 和 Value

具体而言：

  • Key 路径： 将 Key Up-Projection 矩阵 $W^{UK}$ 吸收到 Query 投影中，使 Query 可以直接与压缩后的 KV Latent 计算相关性
  • Value 路径： 将 Value Up-Projection 矩阵 $W^{UV}$ 与输出投影矩阵 $W^O$ 合并，使加权聚合后的 Latent Vector 可以直接映射到输出空间
$$ (\mathbf q_{t,i}^C)^\top(W_i^{UK}\mathbf c_s^{KV}) = ((W_i^{UK})^\top\mathbf q_{t,i}^C)^\top\mathbf c_s^{KV} $$

$s$ 为历史位置

因此，推理过程中不需要显式构造完整的 K、V，就可以完成 Attention 计算

最终，MLA 在推理时主要缓存：

  • KV Latent：$\mathbf{c}_t^{KV}$
  • 共享的位置 Key：$\mathbf{k}_t^R$

Sparse Attention（稀疏注意力）

标准 Self-Attention 中，每个 Query 都需要与所有历史 Key 计算相关性，随着上下文长度增加，计算开销呈二次增长

但在实际场景中，并不是所有历史 Token 都对当前 Token 的信息预测同样重要

因此，可以通过限制 Attention 的计算范围，只选择部分 Token 参与注意力计算

对于位置 $t$ 的 Query，定义其选择的历史 Token 集合为：

$$ \mathcal{S}_t\subseteq\{1,2,\ldots,t\} $$
当每个 Query 只选择固定数量 $k$ 的 Token 时，Attention 的计算复杂度可以由：
$$ O(L^2d)\rightarrow O(Lkd) $$

Fixed Sparse Pattern

提前规定哪些 Token 之间可以进行信息交互，不需要额外的动态选择模块

1.Sparse Transformer

[1904.10509] Generating Long Sequences with Sparse Transformers

核心思想： 将完整 Attention 矩阵分解为多个具有稀疏连接模式的 Attention 矩阵，通过不同稀疏模式的组合，在减少计算量的同时保留远距离信息交互能力

主要提出两种稀疏模式：

  • Strided Attention： 结合局部连续连接与固定步长的跨位置连接，使 Token 同时捕获局部信息和远距离信息，适合图像等具有规则空间结构的数据
  • Fixed Attention： 将序列划分为多个 Block，每个 Block 内进行局部 Attention，同时设置固定的汇聚位置，负责跨 Block 的信息传递，更适合文本等缺乏周期结构的数据

其计算复杂度可以降低至 $O(L\sqrt{L})$

2. Sliding Window Attention

[2004.05150] Longformer: The Long-Document Transformer

核心思想： 将每个 Token 的注意力范围限制在固定窗口内，减少计算量，并通过稀疏的远距离连接弥补局部注意力的不足

主要包含三种机制：

  • Local Window Attention： 关注固定窗口内的局部 Token
  • Dilated Attention： 在窗口中引入间隔采样，扩大信息交互范围
  • Global Attention： 指定少量全局 Token，使其能够与整个序列交互

当窗口大小和全局 Token 数量固定时，计算复杂度可以随序列长度近似线性增长

代表模型： Mistral 7B 将 Sliding Window Attention 与 GQA 结合，每个 Token 只关注前面固定窗口内的历史信息

[2310.06825] Mistral 7B

3. Block Sparse Attention（块稀疏注意力）

[2007.14062] Big Bird: Transformers for Longer Sequences

现代大模型核心组件

现代大模型通常会在原始 Transformer 上采用一组工程化改进

组件 作用
RMSNorm 简化归一化计算并稳定激活尺度
SwiGLU 使用门控结构增强 FFN 表达能力
RoPE 旋转 Q/K，使注意力分数包含相对位置关系
MoE 通过稀疏激活扩大模型参数容量

RMSNorm

[1910.07467] Root Mean Square Layer Normalization

LayerNorm：

$$ \operatorname{LayerNorm}(x) = \gamma \frac{x-\mu} {\sqrt{\sigma^2+\epsilon}} + \beta $$
RMSNorm 可以看作 LayerNorm 的简化版本：
$$ \operatorname{RMSNorm}(x)=\gamma\odot\frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^{d}x_i^2+\epsilon}} $$

相比 LayerNorm，RMSNorm：

  • 减少了均值计算和相关运算；
  • 保留输入的整体方向信息；
  • 对输入的正比例缩放具有不变性；
  • 在许多模型中能以更低计算成本取得与 LayerNorm 相近的效果

RMSNorm 已被 Llama、Mistral、Qwen、Gemma 等许多现代 Decoder-only LLM 广泛采用

SwiGLU

[2002.05202] GLU Variants Improve Transformer

传统 Transformer FFN 通常写成：

$$ \operatorname{FFN}(x)=W_2\phi(W_1x+b_1)+b_2 $$
普通 FFN 只有一条升维分支

SwiGLU加入门控，使用两条分支

一条分支产生内容，一条分支决定这些内容应该保留、放大还是抑制

标准 GLU：

$$ \operatorname{GLU}(x)=(W_v x+b_v)\odot\sigma(W_g x+b_g) $$
SwiGLU 将门控分支中的激活函数换成 SiLU：
$$ \operatorname{SwiGLU}(x)=\operatorname{SiLU}(W_g x)\odot(W_u x) $$

混合专家结构 MoE

[2101.03961] Switch Transformers: Scaling to Trillion Parameter Models with Simple and Efficient Sparsity

[2401.06066] DeepSeekMoE: Towards Ultimate Expert Specialization in Mixture-of-Experts Language Models

在普通稠密 Transformer 中，每个 Token 都经过同一个 FFN

主要问题：

  • 所有 Token 使用相同参数；
  • 增大 FFN 参数量时，每个 Token 的计算量同步增加；
  • 总参数量与单 Token 计算量紧密绑定。

MoE 的目标是：增加模型总参数容量，但每个 Token 只激活其中少量专家，使总参数量大幅增长，而单 Token 计算量不按相同比例增长。

可以把 Transformer 粗略理解为：Attention 做跨 Token 的信息混合，FFN 做 Token 内的通道/特征变换

因此 FFN 很适合进行专家化

Router 通常是一个较小的线性层：

$$ z=W_rx, \qquad W_r\in\mathbb{R}^{E\times d} $$
其中 $z$ 包含每个专家的路由分数，再根据具体模型使用 Softmax、Sigmoid 或其他方式选择 Top-K

第 $i$ 个专家可以写成：

$$ E_i(x) = W_{\mathrm{down},i} \left[ \operatorname{SiLU}(W_{\mathrm{gate},i}x) \odot (W_{\mathrm{up},i}x) \right] \qquad \text{SiLU} = x\sigma(x) $$
最终输出：
$$ y(x) = \sum_{i\in\operatorname{TopK}(g(x))} p_i(x)E_i(x) $$
一个 Token 可以经过：
  1. 始终启用的 Shared Expert，共享专家（非必须）
  2. Router 选择的 Routed Expert，路由专家

忽略残差连接时：

$$ y(x) = \sum_{j=1}^{N_s}E_j^{\mathrm{shared}}(x) + \sum_{i\in\operatorname{TopK}(g(x))} p_i(x)E_i^{\mathrm{routed}}(x) $$
DeepSeekMoE 将这种设计称为 Shared Expert Isolation，共享专家隔离

MoE 的主要训练问题是：路由不均衡，热门专家可能过载，而冷门专家得不到充分训练

线性注意力

[2006.16236] Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention

线性注意力和 MQA / GQA / MLA 不属于同一种压缩思路

  • MQA / GQA / MLA：减少每个 Token 需要保存的 KV 信息量，但历史 Token 仍然分别存在，因此缓存大小仍然随序列长度增长
  • Linear Attention：不再保存每个历史 Token 的独立 (K,V)，而是不断把历史信息累积进一个固定大小的状态（state）

改变计算顺序

线性注意力要求相似度函数可以写成

$$ \operatorname{sim}(q,k) = \phi(q)^\top\phi(k) $$
其中
$$ \phi:\mathbb R^{d_k}\rightarrow\mathbb R^m $$
先分别对 Query 和 Key 做一个特征映射，然后相似度直接写成二者的内积

代入 Attention

$$ y_t = \frac{ \sum_{i=1}^{t} \phi(q_t)^\top\phi(k_i)v_i }{ \sum_{i=1}^{t} \phi(q_t)^\top\phi(k_i) } $$
因为对于固定的 $t$，$\phi(q_t)$ 与求和下标 $i$ 无关，所以可以提到求和外面
$$ y_t = \frac{ \phi(q_t)^\top \left( \sum_{i=1}^{t} \phi(k_i)v_i^\top \right) }{ \phi(q_t)^\top \left( \sum_{i=1}^{t} \phi(k_i) \right) } $$
**利用矩阵乘法结合律，把“Query 分别和所有历史 Key 计算改成先把历史 Key-Value 汇总起来**

定义：

$$ S_t = \sum_{i=1}^{t} \phi(k_i)v_i^\top\qquad z_t = \sum_{i=1}^{t}\phi(k_i) $$
那么 Attention 输出就变成
$$ y_t = \frac{ \phi(q_t)^\top S_t }{ \phi(q_t)^\top z_t } $$
$S_t$ 和 $z_t$ 的大小不随序列长度 $t$ 增长

历史最终都被压缩进

$$ S_t\in\mathbb R^{m\times d_v} \qquad z_t\in\mathbb R^m $$
复杂度约为
$$ O(Nd^2) $$

递归更新

$$ q'_t=\phi(q_t), \qquad k'_t=\phi(k_t) $$

状态更新：

$$ S_t=S_{t-1}+k'_tv_t^\top\\ z_t=z_{t-1}+k'_t $$

和 RNN 非常像

普通 RNN

$$ h_t=F(h_{t-1},x_t)\qquad y_t=G(h_t,x_t) $$
因此，可以把线性注意力的隐藏状态定义为：
$$ h_t^{\mathrm{LA}}=(S_t,z_t) $$
其状态更新函数为：
$$ h_t^{\mathrm{LA}}=F(h_{t-1}^{\mathrm{LA}},x_t)=\left(S_{t-1}+k'_tv_t^\top,z_{t-1}+k'_t\right) $$
从这个角度看，线性注意力本质上是一个具有矩阵隐藏状态的 RNN

Linear Attention 在自回归推理时可以使用 RNN 式递归更新；训练时则可以利用矩阵计算、前缀扫描或分块方法进行并行计算

特征映射

标准 Softmax Attention 使用

$$ \operatorname{sim}(q,k) = \exp(q^Tk) $$
Linear Attention 将相似度函数替换成另一个可以显式分解的 Kernel，并选择：
$$ \phi(x) = \operatorname{ELU}(x)+1 = \begin{cases} x+1,&x>0,\\ e^x,&x\leq0 \end{cases} $$
可以保证 $\phi(x)>0$，作为一种非负的 Attention 相似度

从 Kernel 的角度，指数点积核理论上可以写成某个特征空间中的内积，但对应的特征空间通常是无限维的

因此 Linear Attention 与标准 Softmax Attention 并不完全等价，而是定义了一种新的 Attention 机制

GLA

[2312.06635] Gated Linear Attention Transformers with Hardware-Efficient Training

基础线性注意力：

$$ S_t = S_{t-1} + k_tv_t^\top $$

旧状态只能持续累积，不能根据当前输入选择性遗忘

一种简单方式是加入固定衰减：

$$ S_t = \gamma S_{t-1} + k_tv_t^\top, \qquad 0<\gamma<1 $$
更一般地：
$$ S_t = G_t\odot S_{t-1} + k_tv_t^\top $$
GLA 根据当前输入计算遗忘门：
$$ \alpha_t = f_\alpha(x_t), \qquad \alpha_t\in(0,1)^{d_k} $$
状态更新：
$$ S_t = \operatorname{Diag}(\alpha_t) S_{t-1} + k_tv_t^\top $$
因此：GLA 仍然是一个具有矩阵隐藏状态的 RNN，只是其状态转移由当前输入动态控制
