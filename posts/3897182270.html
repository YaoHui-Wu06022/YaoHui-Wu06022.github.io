视觉 Backbone

Resnet

[1512.03385] Deep Residual Learning for Image Recognition

核心思想： 通过引入 Residual Learning（残差学习）和 Shortcut Connection（快捷连接），将网络原本需要学习的完整映射转换为残差映射，使深层网络更容易优化，从而有效解决网络深度增加带来的Degradation Problem

Degradation Problem

随着 CNN 网络深度增加，理论上模型应该具有更强的特征表达能力，但实际实验发现，网络加深到一定程度后，训练误差反而可能增加

这一现象称为 Degradation Problem（网络退化问题）

ResNet 认为，新增网络层理论上至少可以学习 Identity Mapping（恒等映射），保持原有网络的性能

论文提出通过 Residual Learning 改变网络的学习目标

Residual Learning

传统网络直接学习目标映射 $H(x)$

ResNet 将其重新表示为：

$$ F(x)=H(x)-x $$
因此，原始映射可以写成：
$$ H(x)=F(x)+x $$
当目标映射接近恒等映射时，网络只需要让 $F(x)$ 接近零，而不需要通过多层非线性变换直接拟合 $x$

Shortcut Connection

根据输入与输出的维度关系，Shortcut 分为两种形式：

类型 实现方式 使用场景
Identity Shortcut 直接传递输入 $x$ 输入输出维度一致
Projection Shortcut 使用 1×1 Conv 调整维度 通道数或空间尺寸发生变化

当维度不一致时，使用 Projection Shortcut：

$$ y=F(x)+W_sx $$

BasicBlock & Bottleneck

ResNet 根据网络深度设计了两种主要的 Residual Block：

类型 结构 代表网络
BasicBlock 3×3 Conv → 3×3 Conv ResNet-18 / 34
Bottleneck 1×1 Conv → 3×3 Conv → 1×1 Conv ResNet-50 / 101 / 152

**Bottleneck：**减少 3×3 卷积的计算开销，使网络能够在较低计算成本下扩展到更深的层数

VIT

[2010.11929] An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

核心思想： 将图像划分为固定大小的 Patch，并将其转换为 Token 序列，直接使用标准 Transformer Encoder 进行视觉特征提取，摆脱传统 CNN 对卷积结构的依赖

Patch Embedding

将输入图像划分为互不重叠的 $P\times P$ Patch，每个 Patch 展平后通过线性层映射到固定维度 $D$

$$ x\in\mathbb{R}^{H\times W\times C}\qquad N=\frac{HW}{P^2}=\frac{H}{P}\frac{W}{P} $$
对于 ViT-B/16：
$$ H = W = 224\quad P = 16 \rightarrow N = 196 $$
把每个 Patch 展平成一个向量
$$ {x}_p\in\mathbb{R}^{N\times(P^2C)} $$
通过线性投影对 Patch 维度进行压缩，固定到 $D$，，再输入 Transformer

每个 Patch 就对应 Transformer 中的一个 token

$$ z \in \mathbb{R}^{N\times D} $$

Position Embedding

原始 ViT 延续 BERT 的设计

  • CLS Token：在 Patch Tokens 前加入一个可学习的 [CLS] Token，用于聚合全局图像信息，最终用于分类
  • Position Embedding：为每个 Token 添加可学习的一维位置编码，保留 Patch 的位置信息

输入序列：

$$ z_0=[x_{cls};x_1E;x_2E;...;x_NE]+E_{pos} \qquad E_{pos}\in\mathbb R^{(N+1)\times D} $$

Transformer Encoder

CNN vs ViT

ViT 与 CNN 的核心区别在于 Inductive Bias（归纳偏置）

对比 CNN ViT
特征提取 Convolution Self-Attention
局部性 内置 Locality Bias 主要依赖数据学习
空间关系 局部卷积与层次结构 Position Embedding + Attention
信息交互 逐层扩大感受野 全局信息交互
数据需求 相对较少 通常需要大规模预训练

CNN 通过卷积结构天然引入归纳偏置，ViT 使用较少的图像特定归纳偏置，更多依赖大规模数据学习空间关系

因此，ViT 在大规模数据预训练下能够展现出很强的视觉表征能力，但在数据规模较小时，通常不如具有较强视觉归纳偏置的 CNN 容易训练

技术贡献： ViT 证明了不依赖传统卷积结构，仅使用标准 Transformer 处理图像 Patch 序列，也能够获得具有竞争力的视觉表征，为后续纯 Transformer 视觉 Backbone 的发展奠定了基础

Swin Transformer

[2103.14030] Swin Transformer: Hierarchical Vision Transformer using Shifted Windows

核心思想： 通过 Window-based Self-Attention 将全局注意力限制在局部窗口内，并利用 Shifted Window 实现跨窗口信息交互，同时引入 Patch Merging 构建层次化特征表示，使 Transformer 能够以较低计算开销适配高分辨率图像和密集视觉任务

Patch Embedding

Swin 保留图像的二维空间结构，而不是像 ViT 一样直接将图像作为一维序列处理

原论文使用 $P=4$，将输入图像划分为二维网格，再通过 Linear Projection 映射到特征维度

每个 $4\times4\times3$ 的 Patch 被展平成一个长度为 48 的向量

实现空间下采样

Window-based Self-Attention

ViT 使用 Global Self-Attention，每个 Patch Token 都需要与其他所有 Token 计算注意力，计算复杂度随 Token 数量呈平方增长

Swin Transformer 将图像划分为多个互不重叠的 Local Window，只在每个窗口内部执行 Self-Attention

假设每个 Window 包含 $M\times M$ 个 Patch，原始特征图包含 $h\times w$ 个 Patch，则：

  • Global Attention：每个 Token 与全部 $hw$ 个 Token 交互
  • Window Attention：每个 Token 只与所在窗口的 $M^2$ 个 Token 交互

当 Window Size 固定时，Window Attention 的计算复杂度随图像 Token 数量线性增长

$$ \Omega(\text{Global})=2(hw)^2C\\ \Omega(\text{Window})=2M^2hwC $$
原论文默认窗口大小为 ($7\times7$)

Shifted Window

仅使用 Window Attention 会产生一个问题：不同 Window 之间无法直接进行信息交互

Swin Transformer 引入 Shifted Window，交替使用两种窗口划分方式：

  • W-MSA： 使用常规窗口划分，在各个局部窗口内计算 Attention
  • SW-MSA： 将窗口划分整体移动，使新窗口跨越原有窗口边界，从而建立不同窗口之间的信息交互

通过在相邻 Transformer Block 中交替使用 W-MSA 和 SW-MSA，模型既能保持局部注意力的计算效率，又能逐步实现跨窗口的信息融合

Hierarchical Representation

ViT 在整个网络中保持相同的 Token 数量和特征分辨率，主要输出单一尺度的视觉特征，不利于物品检测和语义分割等需要多尺度特征的任务

Swin Transformer 引入 Patch Merging，在不同 Stage 之间合并相邻的 $2\times2$ Patch：

  1. 将相邻的 4 个 Token 特征进行拼接，通道维度由 $C$ 变为 $4C$
  2. 通过 Linear Layer 将通道维度映射为 $2C$
  3. 特征图的空间分辨率降低为原来的 $1/2$

这种设计使浅层保留较高分辨率的细粒度特征，深层逐渐提取低分辨率的高层语义特征

对比 ViT Swin Transformer
Attention Global Attention Window Attention
信息交互 全局 Token 交互 局部交互 + Shifted Window
特征分辨率 单一尺度 层次化多尺度
计算复杂度 随 Token 数量平方增长 固定窗口下随 Token 数量线性增长
主要适用场景 图像分类 分类、检测、分割等视觉任务

相对位置偏置

Swin 在 Attention 中引入 Relative Position Bias（相对位置偏置），将 Token 之间的相对空间位置关系加入 Attention 计算

$$ \operatorname{Attention}(Q,K,V)=\operatorname{Softmax} \left(\frac{QK^T}{\sqrt d}+B\right)V $$
其中 $B$ 表示可学习的相对位置偏置，使模型能够利用窗口内部的空间位置信息
$$ \hat B= \begin{bmatrix} b_{-(M-1),-(M-1)} & \cdots & b_{-(M-1),M-1}\\ \vdots & & \vdots\\ b_{M-1,-(M-1)} & \cdots & b_{M-1,M-1} \end{bmatrix} \in \mathbb{R}^{(2M-1)\times(2M-1)} $$

ConvNeXt

[2201.03545] A ConvNet for the 2020s

核心思想： 通过将 Vision Transformer 的设计思想引入传统 CNN，对 ResNet 进行系统性现代化改造，在不使用 Self-Attention 的情况下，构建出具有竞争力的纯卷积视觉 Backbone

ConvNeXt Block

ConvNeXt 最终形成的 Block 结构：

Depthwise Convolution

传统卷积同时完成：

  • Spatial Mixing：融合邻域空间信息
  • Channel Mixing：融合不同通道的信息

ConvNeXt 将两种操作显式拆开

  • Depthwise Conv：每个 Channel 独立进行空间卷积，提取局部空间特征
  • 1 × 1 Conv：融合不同 Channel 的信息

这种设计与 Transformer Block 中 Attention 负责 Token 之间的信息交互、MLP 负责特征维度变换的思想相似

从参数量上来看：

  • 普通卷积

    $$ Params=K^2C_{in}C_{out} $$

  • Group Conv (分组 $G = Cardinality$)

    $$ \mathrm{Params}=\frac{K^2C_{in}C_{out}}{G} $$

  • Depthwise Conv 可以看作 $G=C_{\text{in}}$，并且通常 $C_{\text{out}}=C_{\text{in}}$

    $$ Params=K^2C_{in} $$

技术贡献： ConvNeXt 通过系统性实验表明，现代 CNN 可以吸收 Transformer 的许多架构设计，在不引入 Self-Attention 的情况下达到与层次化 Vision Transformer 相当甚至更好的性能，重新证明了卷积架构在现代视觉任务中的竞争力

自监督视觉表征

Moco

[1911.05722] Momentum Contrast for Unsupervised Visual Representation Learning

核心思想： 将 Contrastive Learning 视为 Dictionary Look-up，通过 Queue 维护大量 Negative Samples，并使用 Momentum Encoder 保证不同 Batch 生成的特征具有一致性，从而摆脱对大 Batch Size 的依赖

Dictionary as a Queue

  • Query： 当前图像经过 Query Encoder 得到的特征
  • Positive Key： 同一图像的另一种增强视图经过 Key Encoder 得到的特征
  • Negative Keys： 来自其他图像的特征，存储在 Dictionary

MoCo 使用 Queue 维护 Dictionary：

  1. 将当前 Mini-batch 生成的 Key 加入 Queue(Enqueue)
  2. 移除最早加入的 Key(Dequeue)
  3. Queue 始终保存最近若干个 Mini-batch 的特征

核心作用： 将 Dictionary Size 与 Batch Size 解耦，使模型能够在不增加当前 Batch Size 的情况下获得大量 Negative Samples

Momentum Encoder

Queue 引入了一个问题：不同时间加入 Queue 的 Key 由不同训练阶段的 Encoder 生成

如果 Encoder 参数变化过快，Dictionary 中的特征就可能缺乏一致性

MoCo 引入 Momentum Encoder，使用两个 Encoder：

  • Query Encoder： 通过反向传播正常更新参数
  • Key Encoder： 不通过反向传播更新，而是通过 Query Encoder 的参数进行动量更新

参数更新公式：

$$ \theta_k \leftarrow m\theta_k+(1-m)\theta_q $$
这种更新方式使 Key Encoder 的参数变化更加平滑，保证不同 Mini-batch 生成的 Key 具有较好的一致性

Contrastive Loss

MoCo 使用 InfoNCE Loss，将 Query 与一个 Positive Key 以及 Queue 中的 Negative Keys 进行对比：

$$ \mathcal{L}_q=-\log \frac{\exp(q\cdot k^+/\tau)} {\exp(q\cdot k^+/\tau)+\sum_{i=1}^{K}\exp(q\cdot k_i^-/\tau)} $$

SimCLR

[2002.05709] A Simple Framework for Contrastive Learning of Visual Representations

核心思想： 通过对同一图像进行不同的数据增强，构造正样本对，利用 Contrastive Learning 拉近正样本之间的特征距离、推远不同图像之间的特征距离，从而在没有人工标签的情况下学习视觉表征

Contrastive Learning

SimCLR 的核心是实例判别：将同一张图像经过不同数据增强得到的两个视图视为Positive Pair，Batch 中将其他图像的增强视图作为 Negative Samples

整体框架包含四个部分：

  1. Data Augmentation： 对图像进行随机裁剪与缩放、颜色扰动和高斯模糊，生成两个相关视图
  2. Encoder： 使用神经网络 $f(\cdot)$ 提取图像特征，原论文采用 ResNet
  3. Projection Head： 使用 MLP $g(\cdot)$ 将特征映射到对比学习空间
  4. Contrastive Loss： 通过 NT-Xent Loss 最大化 Positive Pair 之间的一致性

预训练结束后，丢弃 Projection Head，只保留 Base Encoder，用于下游视觉任务

Data Augmentation

论文指出，数据增强组合对学习有效表征至关重要

  • 单独使用某一种数据增强，无法获得较好的视觉表征
  • Random Cropping 与 Color Distortion 的组合尤为重要
  • 仅使用随机裁剪时，不同裁剪区域可能保留相似的颜色分布，模型容易利用颜色统计信息完成实例区分，而不是学习更具泛化性的视觉特征
  • 自监督对比学习通常需要比监督学习更强的数据增强

Projection Head

SimCLR 引入一个非线性 Projection Head，将 Encoder 输出的特征映射到对比学习空间：

$$ z=g(h)=W^{(2)}\sigma(W^{(1)}h) $$
**关键设计：** Contrastive Loss 作用于 $z$，而不是直接作用于 Encoder 输出的 $h$

训练完成后，丢弃 Projection Head，保留 Encoder 输出的 $h$ 用于下游任务，效果更佳

论文指出：对比学习要求 $z$ 对数据增强保持不变，如果直接在 $h$ 上施加 Contrastive Loss，就会迫使 Encoder 输出满足数据增强不变性，可能损失对下游任务有用的信息

Projection Head是为了将对比学习的优化约束与最终需要的视觉表征适当解耦

NT-Xent Loss

对于一个包含 $N$ 张图像的 Batch，每张图像经过两次独立的数据增强，最终得到 $2N$ 个视图

对于任意一个 Anchor：

  • 1 个 Positive Sample：来自同一张原始图像的另一种增强视图
  • $2(N-1)$ 个 Negative Samples：来自 Batch 中其他图像的增强视图

损失函数：

$$ \ell_{i,j}= -\log \frac{\exp(\operatorname{sim}(z_i,z_j)/\tau)} {\sum_{k=1}^{2N}\mathbf{1}_{[k\neq i]} \exp(\operatorname{sim}(z_i,z_k)/\tau)} $$
其中：
  • $\operatorname{sim}$：经过 L2 Normalization 后的 Cosine Similarity
  • $\tau$：Temperature，控制相似度分布的集中程度

核心作用： 提高 Positive Pair 的相似度，同时降低其与 Negative Samples 的相似度

最终对 Batch 中所有正样本对的两个方向 $(i,j)$ 和 $(j,i)$ 计算损失

MoCo SimCLR
负样本来源 Queue 当前 Batch
Encoder Query / Key Encoder 共享 Encoder
关键机制 Momentum Update Projection Head
损失函数 InfoNCE NT-Xent
主要特点 大规模、一致的动态 Dictionary 简洁的对比学习框架

MAE

[2111.06377] Masked Autoencoders Are Scalable Vision Learners

核心思想：将图像随机划分为 Patch，并 Mask 掉大部分 Patch，让模型根据剩余可见区域重建原始图像，通过重建任务学习通用视觉表征，减少对人工标注数据的依赖

Masking Strategy

MAE 将图像划分为固定大小的 Patch

  • Random Masking： 均匀随机采样，不放回地选择可见 Patch
  • Masking Ratio： 默认采用 75% 的 Masking Ratio，只保留 25% 的可见 Patch

高比例 Masking 能够减少图像中的空间冗余，使模型无法简单地通过邻近 Patch 的纹理或颜色进行重建，而需要利用更大范围的上下文信息理解图像

Asymmetric Encoder-Decoder

MAE 最重要的设计是非对称 Encoder-Decoder 架构

Encoder

  • 使用标准 ViT 作为视觉编码器
  • 只处理可见 Patch，不输入 Mask Token
  • 提取可见区域的视觉特征

Decoder

  • 将 Encoder 输出与 Mask Token 组合，恢复完整 Token 序列
  • 使用轻量级 Transformer Decoder 重建原始图像
  • 预测每个 Patch 的像素值

关键设计： Mask Tokens 不进入 Encoder，而是在 Encoder 之后加入 Decoder，这样计算量较大的 Encoder 只需要处理少量可见 Patch，而完整 Token 序列由轻量级 Decoder 处理

论文报告，这种设计可以实现 3 倍以上的训练加速

Reconstruction Loss

MAE 直接以原始图像 Patch 的像素值作为重建目标，使用 MSE Loss，仅在被 Mask 的 Patch 上计算损失：

$$ L=\frac{1}{|M|}\sum_{i\in M} |\hat{x}_i-x_i|_2^2 $$
预训练结束后，丢弃 Decoder，仅保留 Encoder

可以通过 Fine-tuning 适配图像分类、目标检测等任务

DINO

[2104.14294] Emerging Properties in Self-Supervised Vision Transformers

核心思想： 通过 Teacher-Student Self-Distillation，让 Student 网络学习 Teacher 网络对同一图像不同视图产生的输出分布，在没有人工标签的情况下学习视觉表征

Self-Distillation(自蒸馏)

DINO 将知识蒸馏引入自监督学习，构建两个具有相同网络架构的模型：

  • Student： 接收图像增强视图，通过反向传播更新参数

  • Teacher： 接收图像增强视图，不进行反向传播，通过 Student 参数的指数移动平均（EMA）更新

    $$ \theta_t \leftarrow m\theta_t+(1-m)\theta_s $$
    这种方式使 Teacher 的参数变化更加平滑，为 Student 提供相对稳定的学习目标

How AI Taught Itself to See DINOv3

两个网络均由 Backbone(VIT) 和 Projection Head 组成

预训练结束后，通常保留 Teacher 的 Backbone，丢弃 Projection Head，使用 Backbone 提取的特征进行下游任务

与 SimCLR 不同，DINO 不需要显式构造负样本，而是让 Student 预测 Teacher 输出的概率分布

Multi-Crop Training

DINO 引入多尺度裁剪策略，对同一张图像生成不同尺度的视图：

  • Global Crops： 两个较大的图像裁剪，Teacher 和 Student 均接收
  • Local Crops： 多个较小的图像裁剪，仅输入 Student

Teacher 只处理 Global Crops，Student 处理所有 Global 和 Local Crops

核心作用： 通过让 Student 的局部视图匹配 Teacher 的全局视图，建立局部到全局的语义对应关系，使模型能够从局部图像中学习全局语义信息

Centering & Sharpening

Teacher-Student 自蒸馏存在一个问题：Representation Collapse(表征坍塌)，即模型可能对不同输入都输出相同或近似的特征分布，无法学习有效表征

DINO 使用 Centering 和 Sharpening 两种操作平衡 Teacher 的输出分布：

  • Centering： 对 Teacher 输出进行中心化，避免某一个输出维度长期占据主导地位，但可能使输出趋向均匀分布
  • Sharpening： 使用较低的 Temperature，使 Teacher 输出分布更加尖锐，避免输出过于均匀

维护一个 Center 向量 $c$，用来记录 Teacher 在训练过程中各个输出维度的平均值(未softmax)：

并没有事先预设类，只是把输出维度定的很大，让模型自己理解广义上的类

$$ c\leftarrow mc+(1-m)\frac{1}{B}\sum_{i=1}^{B}g_{\theta_t}(x_i) $$

Teacher 和 Student 的输出分布分别为：

$$ p_t=\operatorname{Softmax}\left(\frac{g_{\theta_t}(x)-c}{\tau_t}\right)\qquad p_s=\operatorname{Softmax}\left(\frac{g_{\theta_s}(x)}{\tau_s}\right) $$
最终使用交叉熵损失，让 Student 匹配 Teacher 的输出分布：
$$ \mathcal{L}_{DINO}=-\sum_k p_t(k)\log p_s(k) $$

iBOT

[2111.07832] iBOT: Image BERT Pre-Training with Online Tokenizer

核心思想： 将掩码图像建模 转化为 Teacher-Student Self-Distillation，通过 Teacher 作为 Online Tokenizer，为 Student 提供被遮挡 Patch 的语义特征监督，同时利用 CLS Token 自蒸馏学习全局视觉语义

Online Tokenizer

传统掩码图像建模需要使用预训练的视觉编码器生成重建目标

iBOT 使用 Momentum Teacher 作为 Online Tokenizer：

  • Teacher： 输入完整图像，通过 Backbone 和 Projection Head 生成 Patch 的软概率分布，作为预测目标
  • Student： 输入经过 Masking 的图像，通过 Mask Token 对应位置预测 Teacher 的输出分布
  • EMA Update： Teacher 参数通过 Student 参数的指数移动平均更新

Dual Self-Distillation

iBOT 同时使用两种自蒸馏目标：

1. CLS-level Self-Distillation

延续 DINO 的设计，对不同增强视图的 CLS Token 进行交叉蒸馏：

  • Teacher：输入未 Mask 的图像视图，提取 CLS Feature
  • Student：输入对应的 Masked View，提取 CLS Feature
  • 通过交叉熵损失让 Student 匹配 Teacher 的输出分布

2. Patch-level Self-Distillation

将掩码图像建模转化为 Patch-level 蒸馏：

  • Teacher：输入未 Mask 的图像，提取所有 Patch 特征
  • Student：输入经过 Block-wise Masking 的图像
  • Student 预测被 Mask 位置对应的 Teacher 特征概率分布
$$ \mathcal{L}_{MIM} = -\sum_{i=1}^{N}m_i P_{\theta'}^{patch}(x_i)^T \log P_{\theta}^{patch}(\hat{x}_i) $$

与 MAE 不同，iBOT 不直接重建原始像素，而是预测 Teacher 提供的语义特征分布

DINOv2

[2304.07193] DINOv2: Learning Robust Visual Features without Supervision

核心思想： 结合 DINO 的图像级自蒸馏与 iBOT 的 Patch 级自蒸馏，并引入大规模高质量数据集和 KoLeo Regularization，训练具有通用性和迁移能力的视觉基础模型

DINO + iBOT

DINOv2 将两种自监督学习目标结合起来，同时学习 Image-level 和 Patch-level 的视觉表征

Image-level(DINO)

延续 DINO 的 Teacher-Student Self-Distillation，让 Student 学习 Teacher 对不同图像视图输出的 CLS Token 分布

这也是为什么需要iBOT，只约束 CLS Token，模型并没有被直接要求学习每个局部 Patch 的语义表征

Patch-level(iBOT)

延续 iBOT 的 Online Tokenizer，让 Student 预测被遮挡 Patch 对应的 Teacher 特征分布

关键设计：

  • 独立投影头： DINOv2 为图像级和 Patch 级任务分别设置独立的投影头，避免两种学习目标相互干扰

    原始 iBOT 使用共享投影头，而 DINOv2 发现独立设计在大规模训练下效果更好

  • Sinkhorn-Knopp 归一化： 使用 Sinkhorn-Knopp 算法平衡 Teacher 输出的概率分布，替代原有的移动平均中心化方案，Student 仍使用 Softmax 归一化

KoLeo Regularization（特征分散正则化）

DINOv2 引入 KoLeo 正则化，鼓励 Batch 内的特征在特征空间中更加均匀地分布

其基本思想是计算每个样本与其他样本之间的最近邻距离，通过最大化最近邻距离，促进特征分散

损失函数：

$$ \mathcal{L}_{KoLeo} = -\frac{1}{n}\sum_{i=1}^{n}\log(d_{n,i})\qquad d_{n,i}=\min_{j\neq i}\|x_i-x_j\|_2 $$
  • Centering：调整 Teacher 输出的维度数值，避免某些输出维度长期占据主导
  • KoLeo：约束不同样本的特征向量之间的距离，促进特征空间分散

两者分别从输出分布和样本特征几何结构两个层面改善表征质量

DINOv3

[2508.10104] DINOv3

核心思想： 在 DINOv2 的自监督学习框架上进一步扩大模型规模，并引入 Gram Anchoring，解决长时间训练过程中局部视觉特征逐渐退化的问题，使模型兼具全局语义与高质量局部空间表征

Dense Feature Degradation

DINOv3 发现，随着模型规模和训练时间增加，出现了全局特征与局部特征表现不一致的问题：

  • Global Features： ImageNet 分类准确率持续提升
  • Dense Features： 语义分割等密集预测任务的性能逐渐下降

论文通过特征相似度图发现：

  1. 随着训练进行，CLS Token 与 Patch Token 之间的余弦相似度逐渐增加
  2. 不同 Patch 之间的相似度图逐渐变得嘈杂
  3. Patch 特征的空间局部性下降，难以准确区分图像中的不同区域

Gram Anchoring

DINOv3 引入 Gram Anchoring，通过约束 Patch Features 之间的相似性结构，维持局部特征的一致性

Gram Matrix： 对同一图像中不同 Patch 的特征进行两两相似度计算

具体过程：

  1. 选取训练早期具有较好局部特征的 Teacher 作为 Gram Teacher
  2. Student 和 Gram Teacher 分别提取图像的 Patch Features
  3. 分别计算两组特征的 Gram Matrix
  4. 通过 Loss 约束 Student 的 Gram Matrix 接近 Gram Teacher
$$ \mathcal{L}_{Gram} = \left\| X_S X_S^T-X_G X_G^T \right\|_F^2 $$

**关键设计：**Gram Anchoring 不直接约束 Student 与 Teacher 的特征向量，而是约束它们之间的相似性结构，这样 Student 的特征仍然可以继续更新，只需要保持 Patch 之间原有的空间关系

在传统视觉任务，DINOv3 已经被当作通用视觉特征提取器使用

视觉语言预训练（VLP）

双塔式图文对齐

CLIP

[2103.00020] Learning Transferable Visual Models From Natural Language Supervision

核心思想： 利利用大规模图文配对数据，同时训练 Image Encoder 和 Text Encoder，将图像与文本映射到同一个语义空间，通过对比学习使匹配的图文表示靠近、不匹配的图文表示远离，从而实现跨模态语义对齐和 Zero-shot 分类

Natural Language Supervision

传统视觉模型主要通过人工标注的固定类别进行监督训练，模型的分类能力受到预定义类别的限制，迁移到新任务时通常需要额外的标注数据和训练

CLIP 使用互联网中的自然语言图文配对数据（Image-Text Pairs）作为监督信号：

核心作用： 不再局限于固定的分类标签，而是利用自然语言中更加丰富的语义信息学习视觉表征，使模型能够识别训练时未见过的类别

Dual-Encoder Architecture

CLIP 采用双编码器架构，分别提取图像和文本特征，并将两种模态映射到统一的语义空间

  • Image Encoder： 使用 CNN（ResNet）或 ViT 提取图像特征
  • Text Encoder： 使用 Transformer 提取文本特征，原论文使用最后一层 [EOS] Token 的输出作为文本表示
  • Projection Layer： 分别使用 Linear Projection 将两种特征映射到相同维度的共享语义空间

Contrastive Pre-training

CLIP 的训练目标是判断 Batch 中哪些图文组合是真实匹配的

对于一个包含 $N$ 组图文配对的 Batch：

$$ (I_1,T_1),(I_2,T_2),\ldots,(I_N,T_N) $$
可以组成 $N^2$ 种图文组合：
  • 对角线上的 $N$ 个组合是 Positive Pairs
  • 其余 $N^2-N$ 个组合是 Negative Pairs

分别提取图像和文本特征，经过 L2 Normalization 后计算 Cosine Similarity：

$$ S_{ij}=z_I^i\cdot z_T^j=\frac{z_I^i\cdot z_T^j }{ \|z_I^i\|_2\|z_T^j\|_2 } $$
**对比学习目标：**最大化匹配图文对的相似度，同时降低不匹配图文对的相似度

CLIP 同时优化两个方向

Image → Text：给定图像，在 Batch 中找到与其匹配的文本

$$ L_I = -\frac{1}{N} \sum_i \log \frac{ \exp(S_{ii}/\tau) }{ \sum_j \exp(S_{ij}/\tau) } $$
**Text → Image**：给定文本，在 Batch 中找到与其匹配的图像
$$ L_T = -\frac{1}{N} \sum_i \log \frac{ \exp(S_{ii}/\tau) }{ \sum_j \exp(S_{ji}/\tau) } $$
最终损失：
$$ \boxed{ L = \frac{L_I+L_T}{2} } $$

Zero-shot Classification

CLIP 最重要的能力是 Zero-shot 分类：不需要针对新的分类任务重新训练模型，就能够识别未见过的类别

具体过程：

  1. 将类别名称构造成自然语言 Prompt，例如 A photo of a dog
  2. 使用 Text Encoder 提取各类别的文本特征
  3. 使用 Image Encoder 提取待分类图像的特征
  4. 计算图像与各类别文本特征的相似度
  5. 选择相似度最高的文本类别作为预测结果

关键设计： Text Embeddings 可以看作动态生成的 Classification Weights，Text Encoder 相当于根据自然语言描述生成分类器

SigLIP

[2303.15343] Sigmoid Loss for Language Image Pre-Training

核心思想：在 CLIP 双编码器架构的基础上，将 Softmax Contrastive Loss 替换为 Pairwise Sigmoid Loss，将图文匹配转化为独立的二分类任务，降低对 Batch 内全局归一化的依赖，提高训练效率

Sigmoid Loss

CLIP 使用 Softmax Contrastive Loss，对 Batch 内的图文相似度进行归一化，分别计算 Image-to-Text 和 Text-to-Image 的匹配概率

这种方式需要考虑整个 Batch 的相似度分布，分布式训练时通常需要进行跨设备特征聚合（All-Gather），增加了计算和通信开销

SigLIP 将图文匹配重新定义为二分类问题

对于包含 $N$ 组图文配对的 Batch，可以构建 $N\times N$ 个图文组合：

  • Positive Pair： 匹配的图像与文本，对应标签 $z_{ij}=+1$
  • Negative Pair： 不匹配的图像与文本，对应标签 $z_{ij}=-1$

每个图文组合独立判断是否匹配，不再依赖 Softmax 对整个 Batch 进行归一化

SigLIP 的损失函数：

$$ \mathcal{L} = -\frac{1}{|\mathcal{B}|} \sum_{i=1}^{|\mathcal{B}|} \sum_{j=1}^{|\mathcal{B}|} \log \frac{1} {1+\exp\left[-z_{ij}(t x_i^\top y_j-b)\right]} $$
其中：
  • $t$：可学习的相似度缩放系数
  • $b$：可学习的 Bias

Bias 的作用：

一个 Batch 中负样本数量远多于正样本，训练初期容易受到负样本主导，产生较大的优化步长

因此引入可学习 Bias，初始化为 -10，将相似度缩放系数 $t$ 初始化为 10，使模型初始预测更符合正负样本比例，减少训练初期的过度修正

Efficient Training

SigLIP 的 Pairwise Loss 还带来了训练效率上的优势：

  • Batch Size： 不再需要依赖全局 Softmax 归一化，可以在较小 Batch Size 下获得较好的表现，同时支持进一步扩大 Batch Size
  • Distributed Training： 使用分块计算，避免直接构建完整的全局相似度矩阵，降低显存和通信开销

但是仍然需要考虑 Batch 内的正负样本组合，并没有消除 $N^2$ 级别的图文匹配关系

SigLIP-2

[2502.14786] SigLIP 2: Multilingual Vision-Language Encoders with Improved Semantic Understanding, Localization, and Dense Features

核心思想： 在保留 SigLIP 双塔架构和 Sigmoid Loss 的基础上，引入图像描述、自蒸馏和 Masked Prediction 等训练目标，增强模型的全局语义理解、局部视觉表征、空间定位和多语言理解能力

Captioning-based Pretraining

SigLIP-2 在原有 Image Encoder 和 Text Encoder 的基础上，增加 Transformer Decoder，通过 Cross-Attention 融合未经过 MAP Head 池化的视觉特征

借鉴 LocCa，引入三个训练任务：

  • Image Captioning：根据图像生成整体描述，学习图像与自然语言之间的语义关联
  • Referring Expression Prediction：根据文本描述预测对应物体的 Bounding Box
  • Grounded Captioning：给定 Bounding Box，生成对应图像区域的描述

通过图像描述和区域定位任务，让视觉 Encoder 学习更丰富的局部语义和空间信息

训练完成后移除辅助 Decoder，仅保留 Image Encoder 和 Text Encoder

Multi-stage Training

SigLIP-2 采用分阶段训练策略，在原有图文对齐目标的基础上，逐步引入生成任务和自监督目标

Stage 1：图文对齐与生成任务（前 80%）

联合优化两个目标：

  • Sigmoid Loss：保留原有图文对齐能力。
  • LocCa Decoder Loss：通过图像描述和区域定位增强视觉特征

Stage 2：引入自监督目标（最后 20%）

额外引入两个训练目标：

1. Self-Distillation

借鉴 DINO 系列的 Teacher-Student Self-Distillation：

  • Teacher： 接收一个完整的 Global View，提取全局视觉特征
  • Student： 接收 8 个 Local Views，提取局部视觉特征
  • Training Target： 让 Student 的局部特征匹配 Teacher 的全局特征
  • EMA Update： Teacher 参数通过 Student 参数的 EMA 更新

建立全局与局部视觉特征之间的语义一致性

2. Masked Prediction

借鉴 iBOT 的 Masked Prediction 思想，让 Student 预测被 Mask 区域对应的 Teacher Features：

  • Teacher： 输入完整 Global View，提取所有 Patch Features
  • Student： 将同一 Global View 中 50% 的 Patch 替换为 Mask Tokens
  • Training Target： 预测被 Mask 位置对应的 Teacher Patch Features

增强 Patch-level Representation，使模型学习更丰富的局部视觉信息

NaFlex

SigLIP-2 还提供 NaFlex 版本，支持不同分辨率和原生宽高比

NaFlex 融合了两个思路：

  • FlexiViT：使用单一 ViT 支持多种预设序列长度的设计

    [2212.08013] FlexiViT: One Model for All Patch Sizes

    使同一套模型参数能够适应不同长度的 Patch Token 序列

  • NaViT：尽可能保留输入图像的原始宽高比，而不是强制 Resize 为固定正方形

    [2307.06304] Patch n' Pack: NaViT, a Vision Transformer for any Aspect Ratio and Resolution

    通过保持图像宽高比进行缩放，将图像划分为 Patch，并根据目标序列长度进行 Padding

跨模态交互与生成

ALBEF

[2107.07651] Align before Fuse: Vision and Language Representation Learning with Momentum Distillation

核心思想： 先通过对比学习对齐图像和文本的全局语义特征，再通过 Cross-Attention 进行跨模态融合，同时引入 Momentum Distillation，利用动量模型生成软标签，缓解 Web 图文数据中的噪声问题

Align Before Fuse

ALBEF 提出 Align before Fuse，将训练过程分为两个阶段：

  1. Align： 分别使用 Image Encoder 和 Text Encoder 提取特征，通过 Image-Text Contrastive Loss（ITC）先对齐图像与文本的全局语义表示。
  2. Fuse： 将两种模态的特征输入 Multimodal Encoder，通过 Cross-Attention 建立细粒度的跨模态交互

Model Architecture

ALBEF 采用三个 Encoder 构成的架构：

  • Image Encoder：使用 ViT-B/16 提取图像 Patch Features
  • Text Encoder：使用 Transformer 提取文本 Token Features
  • Multimodal Encoder：通过 Cross-Attention 融合图像和文本特征，学习细粒度跨模态关系

Image Encoder 和 Text Encoder 独立提取特征，Multimodal Encoder 再进行深层融合，使模型同时具备单模态表征能力和跨模态交互能力

Pre-training Objectives

ALBEF 联合优化三个训练目标：

训练目标 作用位置 核心作用
Image-Text Contrastive（ITC） Unimodal Encoders 对齐图像和文本的全局语义
Image-Text Matching（ITM） Multimodal Encoder 判断图文是否匹配
Masked Language Modeling（MLM） Multimodal Encoder 利用图像和文本上下文预测被 Mask 的词

ITM

通过 Multimodal Encoder 融合图像和文本特征，使用融合后的 CLS Embedding 判断图文是否匹配

ALBEF 引入 Hard Negative Mining（困难负样本挖掘）：

  • 利用 ITC 计算图像与文本之间的相似度
  • 从 Batch 中按照相似度分布采样负样本
  • 优先采样语义相似但实际不匹配的图文组合

MLM

随机 Mask 15% 的文本 Token，将图像特征和剩余文本输入 Multimodal Encoder，预测被 Mask 的 Token

与传统 BERT 不同，ALBEF 可以利用图像信息辅助文本预测，使语言表征具备视觉语义基础

Momentum Distillation

Web 图文数据通常存在噪声：

  • 图像和文本可能只有部分语义相关
  • 文本可能遗漏图像中的部分物体或属性
  • 对于被 Mask 的词，可能存在多个同样合理的描述

传统训练使用 One-hot Hard Labels，将唯一标注答案作为正确目标，会惩罚其他合理的预测结果

ALBEF 参考DINO引入 Momentum Distillation，利用 Momentum Model 生成 Soft Targets

  • Momentum Model： 由 Image Encoder、Text Encoder 和 Multimodal Encoder 的 EMA 参数构成
  • Pseudo Targets： 使用 Momentum Model 生成预测概率分布，作为额外监督信号
  • Student： 同时学习原始标注和 Momentum Model 提供的软标签

允许模型学习标注之外的合理语义信息，降低噪声图文数据对模型训练的负面影响

BLIP

[2201.12086] BLIP: Bootstrapping Language-Image Pre-training for Unified Vision-Language Understanding and Generation

核心思想： 在 ALBEF 的图文对齐与跨模态融合基础上，引入统一的 Encoder-Decoder 架构和 CapFilt 数据自举机制，使模型同时具备视觉语言理解与生成能力，并通过自动生成和筛选文本缓解 Web 图文数据中的噪声问题

MED Architecture

ALBEF 主要采用 Encoder-based 架构，虽然能够进行跨模态理解，但不便于直接迁移到文本生成任务

BLIP 提出 Multimodal Mixture of Encoder-Decoder（MED），使同一套模型能够根据不同任务切换为三种工作模式：

1. Unimodal Encoder（单模态编码器）

分别使用 Image Encoder 和 Text Encoder 提取图像与文本特征，不进行跨模态交互

  • 使用 CLS Token 提取全局特征
  • 通过 ITC Loss 对齐图像与文本的语义空间

2. Image-grounded Text Encoder（图像条件文本编码器）

在 Text Encoder 的每个 Transformer Block 中增加 Cross-Attention Layer：

  • Self-Attention：建模文本 Token 之间的关系
  • Cross-Attention：以文本特征作为 Query，以图像特征作为 Key 和 Value
  • 使用额外的 [Encode] Token，其输出用于图文匹配

核心作用： 融合图像与文本信息，学习细粒度的跨模态特征，用于 ITM 任务

3. Image-grounded Text Decoder（图像条件文本解码器）

在 Image-grounded Text Encoder 的基础上，将双向 Self-Attention 替换为 Causal Self-Attention：

  • 使用 Causal Mask，使每个 Token 只能关注当前位置之前的 Token
  • 保留 Cross-Attention，使文本生成能够利用图像特征
  • 使用 [Decode] Token 标记生成任务的开始

核心作用： 根据图像特征自回归生成文本，用于 Image Captioning 等生成任务

关键设计： Text Encoder 和 Text Decoder 共享除 Self-Attention 之外的所有参数，包括 Embedding、Cross-Attention 和 FFN，从而减少参数量，同时兼顾理解与生成能力

Pre-training Objectives

BLIP 联合优化三个训练目标，其中 ITC 和 ITM 主要用于视觉语言理解，LM 用于文本生成

Loss 对应模式 核心作用
ITC Unimodal Encoder 对齐图像与文本的全局语义
ITM Image-grounded Text Encoder 判断图文是否匹配
LM Image-grounded Text Decoder 根据图像自回归生成文本

其中 ITC 和 ITM 延续 ALBEF 的设计

与 ALBEF 使用 MLM 不同，BLIP 使用自回归语言建模，使模型能够直接学习图像条件下的文本生成能力

CapFilt（Captioning and Filtering）

BLIP 另一个重要创新是 CapFilt，解决 Web 图文数据存在大量噪声的问题

BLIP 利用预训练好的 MED 模型，进一步微调出两个模块：

1. Captioner（图像描述生成器）

  • 基于 Image-grounded Text Decoder
  • 使用人工标注的图文数据进行微调
  • 输入 Web Image，生成 Synthetic Captions

为原始图像补充更加准确、丰富的文本描述

2. Filter（图文筛选器）

  • 基于 Image-grounded Text Encoder
  • 使用 ITC 和 ITM 目标进行微调
  • 判断原始 Web Text 和 Synthetic Captions 是否与图像匹配
  • 使用 ITM Head 过滤不匹配的图文组合

去除原始文本和合成文本中的噪声，保留与图像内容一致的描述

核心思想：利用模型自身的能力改善训练数据，再利用改善后的数据提升模型能力

BLIP-2

[2301.12597] BLIP-2: Bootstrapping Language-Image Pre-training with Frozen Image Encoders and Large Language Models

核心思想： 冻结预训练好的 Image Encoder 和 Large Language Model（LLM），引入轻量级 Querying Transformer（Q-Former）作为两者之间的连接模块，通过两阶段预训练逐步实现视觉特征提取与语言空间对齐，降低多模态大模型的训练成本

Q-Former Architecture

BLIP-2 最重要的创新是 Q-Former，用于连接冻结的视觉编码器和语言模型

传统方法通常直接将视觉特征输入 LLM，但两种模态的特征空间存在差异，直接连接难以实现有效的跨模态对齐

Q-Former 引入一组可学习的 Query Tokens，从 Image Encoder 提取与语言任务相关的视觉信息，并将其传递给 LLM

整体结构：

  • Image Encoder： 使用预训练的 ViT 提取图像特征，参数保持冻结
  • Q-Former： 通过 Learnable Queries 提取视觉信息，并与文本进行交互
  • LLM： 使用预训练语言模型生成文本，参数保持冻结

Learnable Queries

Q-Former 使用一组可学习的 Query Embeddings 作为输入：

每个 Query 随着训练进行，会学习如何从视觉特征中提取对图文任务有用的信息

原论文使用 32 个 Query Tokens，每个维度为 768，最终得到：

$$ Z\in\mathbb{R}^{32\times768} $$
相比直接使用 ViT 输出的全部 Patch Features，Q-Former 只输出固定数量的 Query Features

Q-Former 形成 Information Bottleneck的作用，从大量视觉特征中提取与文本语义最相关的信息，减少冗余视觉信息，同时使输出长度不再依赖输入图像的分辨率

与 BLIP 的区别：

  • BLIP：主要通过 Text Token 的 Cross-Attention 读取视觉特征
  • BLIP-2：引入可学习 Query，主动从视觉特征中提取信息

Shared Transformer

Q-Former 由两个共享 Self-Attention 层的 Transformer 子模块构成：

  • Image Transformer： 接收 Learnable Queries，通过 Cross-Attention 与冻结的 Image Encoder 特征交互
  • Text Transformer： 接收文本 Token，可以作为 Text Encoder 或 Text Decoder 使用

Cross-Attention 每隔一个 Transformer Block 插入一次，使 Query Tokens 能够逐层提取视觉信息

Two-stage Pre-training

BLIP-2 采用两阶段预训练，逐步完成视觉特征提取和视觉到语言的对齐

Stage 1：Vision-Language Representation Learning

将 Q-Former 连接到冻结的 Image Encoder，通过图文配对数据训练 Q-Former，使 Query Tokens 学习提取与文本语义相关的视觉特征

延续 BLIP 的三个预训练目标：

Loss 核心作用
ITC 对齐图像与文本的全局语义
ITM 学习图像与文本的细粒度匹配
ITG 根据图像生成文本

三个任务通过不同的 Self-Attention Mask 控制 Query 和 Text Token 之间的信息交互

Stage 2：Vision-to-Language Generative Learning

将 Q-Former 输出的 Query Features 映射到 LLM 的词向量空间，使冻结的 LLM 能够理解视觉信息

具体过程：

  1. Q-Former 提取 32 个 Query Features
  2. 通过 FC Layer 将特征映射到 LLM 的词嵌入维度
  3. 将投影后的视觉特征作为 Soft Visual Prompts，拼接到文本 Embedding 前面
  4. 冻结 LLM，根据视觉特征和文本 Prompt 生成目标文本

根据 LLM 的架构，采用不同的训练方式

模块 Stage 1 Stage 2
Image Encoder 冻结 冻结
Q-Former 训练 继续训练
FC Projection Layer 不涉及 训练
LLM 不参与 冻结

技术贡献： BLIP-2 提出 Q-Former 作为视觉编码器与 LLM 之间的信息瓶颈，通过两阶段预训练分别完成视觉特征提取和语言空间对齐，在冻结大型单模态模型的情况下实现高效的多模态学习，为后续视觉语言大模型采用预训练视觉编码器与 LLM 组合的架构提供了重要思路
