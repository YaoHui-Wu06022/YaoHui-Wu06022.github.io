[2010.11929] An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

VIT

核心思想：把一张二维图片切成很多小块（patch），把每个 patch 当成 NLP 中的一个 token，然后直接交给标准 Transformer Encoder

定义图片

$$ \mathbf{x}\in\mathbb{R}^{H\times W\times C} $$
把图片切成 $P\times P$

patch 总数为

$$ N=\frac{HW}{P^2}=\frac{H}{P}\frac{W}{P} $$
再把每个 Patch 展平成一个向量
$$ \mathbf{x}_p\in\mathbb{R}^{N\times(P^2C)} $$
使用一个可以训练的矩阵
$$ \mathbf{E}\in\mathbb{R}^{(P^2C)\times D} $$
把每个 patch 的维度进行压缩得到 **Patch Embedding**
$$ P^2C\rightarrow D $$
就可以得到可以送入Transformer层的语义向量了

在这之前还需要添加一个位置向量

$$ \mathbf E_{pos}\in\mathbb R^{(N+1)\times D} $$

这里 +1 是因为VIT延续了Bert的设计，在开头加了一个[CLS]

以ViT-B/16为例，使用Pytorch

Swin Transformer

[2103.14030] Swin Transformer: Hierarchical Vision Transformer using Shifted Windows

核心思想：把图片切成较小的 Patch，但不把整张图片作为一个长序列做全局 Attention，而是在二维特征图上划分 Window，只在 Window 内做 Attention；然后不断 Patch Merging 下采样，得到多尺度特征

Patch Embedding

定义图片：

$$ \mathbf{x}\in\mathbb{R}^{H\times W\times C} $$
Swin 原论文使用 $P=4$
$$ H\times W\rightarrow\frac H4\times\frac W4 $$
每个 Patch 原始维度为 $4\times4\times C$

再通过 Linear Projection 转换到定义的特征维度

这里和 ViT 最大区别之一是 Swin 更强调保留二维结构

Window Partition

Swin 没有让所有 Token 互相 Attention

而是划分成 7 × 7 Window

然后每一个 49 Token 的小序列再做自注意力

W-MSA

W-MSA：Window Multi-head Self-Attention

第一个 Swin Block 使用 W-MSA Window Multi-head Self-Attention

只允许：

不同 Window 暂时不通信

SW-MSA

SW-MSA：Shifted Window Multi-head Self-Attention

如果连续使用相同的固定窗口划分，那么不同 Window 之间无法通过 W-MSA 直接进行信息交互

第二个 Block 将窗口划分相对于前一个 Block 偏移

移动(这里是按照论文 M = 7 )

$$ \left\lfloor\frac M2\right\rfloor=3 $$
Shift 之后，一个新的 Window 就可能同时包含多个 window 的一部分 token

实现跨 Window 信息交流

因此 Swin Block 通常两个一组

Patch Merging

这是 Swin 和 ViT 非常大的另一个区别

ViT 基本一直保持 token 数不变，而 Swin 会下采样

Swin-T 的 Stage 深度就是 [2,2,6,2]
